# accurate-screen

GLM 계열(ZCode 세션 LLM)의 스크린샷 분석 정확도 문제를 연구하고, 원인 분석 → 우회 기법 실증 →
스킬화까지를 한 번에 정리하는 프로젝트.

## 배경

- GLM 5.3(비전 미포함)은 이미지를 직접 읽지 못해 외부 도구에 의존 → Computer Use 스크린샷
  분석이 느리고 부정확하다.
- GLM 5.3 Flash(비전 포함)도 같은 계열의 실패가 관찰된다:
  1. 앱 테두리가 보이지 않으면 그 픽셀이 어떤 앱의 출력인지 구분하지 못한다.
  2. 화면에 유일하게 표시된 앱인데도 캡처에서 정보를 추출하지 못한다.
- 전제: 도구가 넘겨주는 이미지 데이터가 "모델이 직접 컨텍스트에서 추출하는" 방식(GPT/Claude/
  Gemini 등)과 다르게 취급될 수 있다 — 너무 많이 축소되거나, 근거 메타데이터 없이 던져지거나.

## 구성

- `research/` — 정보 수집·실증 실험·원인 분석 문서 (번호 순서대로 읽을 것)
- `skills/accurate-screen/` — 연구 결과로 만든 스킬 (SKILL.md + scripts/)

## 진행 규칙

- 작업 단위마다 git 커밋.
- 수치 주장은 전부 실측 근거를 붙인다. 추정은 "추정"으로 표기.
- 실증 실험은 세션 LLM 자신(비전 모델)이 판독자로 참여한다 — 판독 성공/실패를 관찰 기록으로 남긴다.
